# AyCode – Downloads

Hier liegen nur die fertigen Installer von AyCode. Der Quellcode ist privat.

**Download:** unter [Releases](https://github.com/Ayont/AyCode-releases/releases/latest) die Datei
`AyCode-<Version>-arm64.dmg` laden (Mac mit Apple-Chip).

Einmalig beim ersten Start: Falls macOS die App blockiert, unter
*Systemeinstellungen → Datenschutz & Sicherheit* auf „Trotzdem öffnen“ klicken.

Danach aktualisiert sich AyCode selbst. Jedes Update ist mit dem Schlüssel des Herausgebers signiert
(`SHA256SUMS` + `SHA256SUMS.sig`); AyCode installiert nur Updates mit gültiger Signatur.
