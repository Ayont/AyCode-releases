# Security

AyCode only installs updates that are signed with the publisher's key: every release ships `SHA256SUMS` and `SHA256SUMS.sig`, and the app checks both before it installs anything.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. You get an answer as soon as possible, and fixes ship as a signed update.

---

**Deutsch:** Sicherheitslücken bitte nicht als öffentliches Issue melden, sondern über **Security → Report a vulnerability** in diesem Repository.
