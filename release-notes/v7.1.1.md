# AyCode 7.1.1

Desktop 7.1.1 · Android 7.1.1 (71001)

iPhone and Apple Watch follow as 7.1.1 (63) via TestFlight.

A bug-fix release for 7.1.0: Claude handles side tasks more cheaply and shows only each project's own commands in that project; chat scrolling and the status line behave calmly again.

## Improved
- **Claude handles side tasks with Haiku.** Start lines, history and the notetaker summary now run on Claude Haiku without thinking, the commit message on the chat model without thinking. That costs considerably less. With your own API address or via Bedrock or Vertex, the chat model is still used. In the Claude settings, "Model for side tasks" decides who takes these tasks: empty for automatic, "main" for the chat model, or a model ID of your own. If the chosen model is not available, AyCode tries once with the chat model.
- **Clearer message when Claude stops.** If the Claude CLI quits in the middle of an answer, the error card is called "CLI ended unexpectedly" and names the cause in plain words instead of a raw English error.

## Fixed
- **Each project shows its own commands.** With several projects open, a Claude chat could offer commands and skills from another project. Now each chat only knows the commands and skills of its project.
- **Start screen without foreign commands.** The start screen and chats that had not reported commands yet sometimes showed the commands and skills of the project that was last active. AyCode now remembers the list per project, also across a restart.
- **Finished Claude answers stay finished.** An error while closing the CLI shortly after an answer ended used to turn it into an error afterwards.
- **The status line next to the thinking orb stays readable.** After a change, the live label lost letters and only something like "h t a" was left. Now it stays complete. Long descriptions and quick successive changes are swapped without the letter animation.
- **The chat no longer scrolls past the end.** Scrolling down with momentum pulled the chat past the end and then let it slide back. Now it stops at the end. Following along only starts again once you are all the way down, and scrolling up lets go immediately.
- **iPhone build.** The archive script now also recognises the team's development certificates.

Desktop 7.1.1 · Android 7.1.1 (71001)

iPhone und Apple Watch folgen als 7.1.1 (63) über TestFlight.

Eine Fehlerbehebungsversion zu 7.1.0: Claude erledigt Nebenaufgaben günstiger und zeigt in jedem Projekt nur dessen eigene Befehle, Chat-Scroll und Statuszeile verhalten sich wieder ruhig.

## Verbessert
- **Claude erledigt Nebenaufgaben mit Haiku.** Startzeilen, Verlauf und die Notetaker-Zusammenfassung laufen jetzt auf Claude Haiku und ohne Denken, die Commit-Message auf dem Chat-Modell ohne Denken. Das kostet deutlich weniger. Mit eigener API-Adresse oder über Bedrock oder Vertex bleibt es beim Chat-Modell. In den Claude-Einstellungen legt „Modell für Nebenaufgaben“ fest, wer diese Aufgaben übernimmt: leer für automatisch, „main“ für das Chat-Modell oder eine eigene Modell-ID. Ist das gewählte Modell nicht verfügbar, versucht AyCode es einmal mit dem Chat-Modell.
- **Klarere Meldung, wenn Claude abbricht.** Endet die Claude-CLI mitten in einer Antwort, heißt die Fehlerkarte „CLI unerwartet beendet“ und nennt die Ursache auf Deutsch statt eines englischen Rohfehlers.

## Behoben
- **Jedes Projekt zeigt seine eigenen Befehle.** Waren mehrere Projekte offen, konnte ein Claude-Chat Befehle und Skills aus einem anderen Projekt anbieten. Jetzt kennt jeder Chat nur die Befehle und Skills seines Projekts.
- **Startbildschirm ohne fremde Befehle.** Der Startbildschirm und Chats, die noch keine Befehle gemeldet hatten, zeigten manchmal die Befehle und Skills des Projekts, das zuletzt aktiv war. AyCode merkt sich die Liste jetzt pro Projekt, auch über einen Neustart hinweg.
- **Fertige Claude-Antworten bleiben fertig.** Ein Fehler beim Schließen der CLI kurz nach dem Ende einer Antwort machte sie bisher nachträglich zum Fehler.
- **Die Statuszeile neben dem Denk-Orb bleibt lesbar.** Nach einem Wechsel verlor das Live-Label Buchstaben, übrig blieb etwa „h t a“. Jetzt bleibt es vollständig. Lange Beschreibungen und schnell aufeinanderfolgende Wechsel werden ohne Buchstabenanimation getauscht.
- **Der Chat scrollt nicht mehr übers Ende hinaus.** Schwungvolles Scrollen nach unten zog den Chat über das Ende hinaus und ließ ihn dann zurückgleiten. Jetzt hält er am Ende an. Das Mitlaufen setzt erst wieder ein, wenn du ganz unten bist, und Scrollen nach oben lässt sofort los.
- **iPhone-Build.** Das Archiv-Skript erkennt jetzt auch die Development-Zertifikate des Teams.
