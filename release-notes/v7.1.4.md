# AyCode 7.1.4

Desktop 7.1.4

Antigravity now offers Claude Opus 5.5 and Claude Sonnet 5.5, each in Low, Medium and High.

## New
- **Claude Opus 5.5 and Sonnet 5.5 in Antigravity.** Antigravity's model picker has six new entries: "Claude Opus 5.5" and "Claude Sonnet 5.5", each with "(Low)", "(Medium)" and "(High)". These are exactly the models `agy models` reports from agy 1.2.16 on. Both have a 1M context, and the usage view prices them at Anthropic's own list price.

## Improved
- **An old Claude 4.6 choice moves along.** agy no longer offers Claude Opus 4.6 and Sonnet 4.6. If you had picked one of them, you land on the same model in 5.5 at the "High" level instead of "Default", and the next turn no longer fails on a model that is gone.
