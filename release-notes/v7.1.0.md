# AyCode 7.1.0

Desktop 7.1.0 · Android 7.1.0 (71000) · iPhone and Apple Watch 7.1.0 (62) follow via TestFlight

Teams and Aylinge move closer together: group chats with several Aylinge on any provider, invitations by GitHub name and team sessions you can follow in the browser, without AyCode at all. Plus one prompt to several models with a side-by-side comparison, diff comments, chats for later, your history as a timesheet, an overview in Settings and a lot that is new on iPhone and Apple Watch: wake the Mac, reply from the notification, Face ID and complications. 7.0.1 was not published; its changes are included here.

## New
- **Team session in the browser, without AyCode.** The invitation page offers "Join in the browser, without AyCode". Anyone who wants to join signs in with GitHub and knocks. Once let in, they follow every chat of the session live (text, tool steps and code), see the tasks and write in the team chat. Steering agents, granting approvals and code stay in the app. The page decrypts everything itself; the cloud still reads nothing. On a phone the page is split into tabs.
- **Invite by GitHub name.** Type `@name` in the share dialog and click "Invite". The invited person sees the invitation in the island and as a notification and is in with "Join", without knocking. Invitations can be withdrawn or declined.
- **Team chat like a messenger.** Reply with a quote, edit and delete your own messages, reactions (👍 ❤️ 😂 🎉 👀) and pinned messages above the conversation.
- **Miss nothing in your team.** The cloud keeps team chat, reactions, comments and tasks sealed. Anyone who was offline gets everything on their return, even if nobody else is online. After a restart the conversation is back.
- **Group chats with Aylinge.** One chat for people and several Aylinge whose providers can be mixed freely. The pinned Ayling answers right away (or decides for itself, or waits for @name), the others react to @name, and @all asks everyone. Aylinge bring each other in and can create new specialists. "Create group" sits in the Aylinge list, on the start screen and in the input box. Ayling chats and groups read like a messenger, with bubbles in the Ayling's colour.
- **Copy an Ayling.** "Create copy" in the profile takes over brief, engine, location, skills and memory. The copy's routines start switched off so nothing runs twice.
- **One prompt to several models.** On the start page, Shift-click (⇧) up to three more models in the picker. Each model gets its own chat, in repositories with its own worktree. "Compare answers" then shows the answers side by side, each with status, time, tool calls and changed files.
- **Comment on diff lines.** In the changes panel, every line shows a comment button on hover. "Into the chat" (or ⌘/Ctrl + Enter) puts the comment into the input box as a quote with file, line and code. Several comments collect in one message.
- **Chats for later.** The chat menu has "Later": in an hour, this evening, tomorrow morning or on Monday. The chat waits in the "Later" section and comes back on its own at the chosen time, or earlier if something happens in it.
- **Answer follow-up questions with an image or file.** The question card has a paperclip, and a pasted image is attached.
- **Long pasted text becomes a file.** From 32 KiB on, AyCode attaches pasted text as a text file instead of filling the input box. "Paste as text anyway" undoes that.
- **Lists continue.** In the input box a new line continues the list, as in AyNotes. An empty line ends it.
- **Projects with their own defaults.** Per project you can set the model and reasoning effort new chats start with. Every project card shows the activity of the last 14 days. A selected project shows its key figures, including cost and tokens of the last 7 days.
- **Mark things in the agent browser.** Via "Mark" in the bar or on the pill, a click marks an element of the page with a number instead of operating it. The agent reads the marks, and "Into the chat" writes them into the input box.
- **History as a timesheet.** History has a search, a "Last 7 days" bar and "Where the time went" with a filter per app (e.g. "Only Xcode"). "Timesheet" copies one day or all matches as Markdown.
- **AyNotes: open tasks.** The start page collects the tasks from the meetings of the last 45 days, tasks with a due date first. You can tick them off there and on the meeting page. "Send open tasks to the agent" sends only what is still open.
- **Graph: path between two notes.** "Path to …" highlights the shortest chain of links between two notes.
- **Settings with an overview.** Settings open with an overview: what needs your attention right now and how each area is doing. The Cloud and Phone pages start with status tiles, and the Cloud page lists all team sessions and invitations. The navigation is reorganised, and "Import" is now called "Move in".
- **Assign keyboard shortcuts freely.** Settings › Keyboard shortcuts (⌘/ or Ctrl + /) lists every shortcut. Global shortcuts can be reassigned or turned off. If a key is already taken, AyCode refuses it.
- **Phones set to "Read only".** Every paired phone can be renamed and set to "Read only". It then sees everything but cannot write, approve, start chats or change settings.
- **Move in from more apps.** The move-in assistant now also recognises T3 Code, Cline, Pi, Oh My Pi, Grok CLI, Mistral Vibe, Cursor, GitHub Copilot CLI and Qwen Code and shows their logos. Imports from T3 Code and Claudian show how far along they are ("12 of 31 chats").
- **AyCode's MCP server for more providers.** DeepSeek Harness (0.2 and later), Vibe (2.22 and later), Pi and Antigravity via the SDK get Brain, the agent browser and your own MCP servers automatically. Antigravity keeps working even if a server does not answer.
- **Pi plans.** "Plan" starts Pi with read-only tools. The result is a plan you start with "Carry out plan".
- **Codex: "Ultra" for GPT-6.1 Sol.** The reasoning levels now come from Codex's model catalogue, so new levels appear without an AyCode update.
- **More targets in the command palette.** ⌘K also opens the projects overview, Aylinge, AyNotes and History.

## New on iPhone and Apple Watch
- **Wake the Mac.** iPhone and Watch send real Wake-on-LAN packets. When the iPhone returns to Wi-Fi or changes networks, it connects right away and wakes the Mac. There is also a Mac widget for the Home and Lock Screen and a switch in Control Center.
- **Reply and approve from the notification.** Under a finished answer there is "Reply", for approvals "Allow" and "Deny" (with Face ID). Under Settings → Notifications you choose what alerts you and whether title and preview appear on the Lock Screen. The app icon counts the chats waiting for you.
- **Privacy & Behavior.** Lock with Face ID (immediately or after 1, 5 or 15 minutes), a cover in the app switcher, a screen that stays awake while an agent works, and a start tab of your choice.
- **New chat from anywhere.** Via Siri ("New chat in AyCode"), Spotlight, Shortcuts, the Action button and `aycode://new`. On the Watch, "New chat" starts with a project choice and dictation.
- **Complications for the Watch.** Who is working, who is waiting and which limit is fullest, right on the watch face.
- **Group chats on the iPhone.** The pinned Ayling sits at the top, and next to every answer is the avatar of the Ayling that wrote it.
- **All eight Aylinge shapes**, including ghost, star, cube and flower, are now on the iPhone, in the widgets and in the screensaver.

## Improved
- **Answers feel alive.** Every word of a running answer fades in gently. Time and steps count along, and the bar, end dot and edge of the input box glow in the colour of the answering provider. Status words morph letter by letter, and numbers (lines, context, limits, usage) roll to their new value. With reduced motion everything stays still.
- **Changes at a glance.** Above the input box a small live preview shows which file the agent is editing right now. Hovering over a step's "+1 −1" or the changes chip shows the changed lines or files. In the sidebar, running chats show their changed lines.
- **The agent's task list ticks off live**, with a rolling counter and a short shine on every tick.
- **Calmer controls.** Delete and remove ask right at the button instead of in a system dialog. "Copy" turns into a check mark in place. Loading placeholders only appear when loading really takes a while.
- **Sidebar and narrow windows.** Waiting and aborted chats carry a short pill ("Waiting", "Error"), in the command palette too. In narrow windows, chips in the chat header step aside entirely instead of being cut off, and the actions in the changes panel wrap.
- **Readability.** Quiet texts (hints, timestamps) have at least 3:1 contrast in every colour theme; the status pills meet AA.
- **Agent browser.** The cursor outlines what it is about to click, and you see every letter while it types. The bar is calmer and has an address field. The window only opens when the agent works in a web app, not for mere reading.
- **Clearer error cards.** If a CLI rejects AyCode's options or is outdated, the card says "CLI version does not match" and offers "Update CLI". Sign-in problems with Grok, Pi, OMP and OpenCode lead to the sign-in card.
- **DeepSeek Harness 0.2.** Thinking, tools and answer appear live, every chat has its own dsh session, and errors such as a missing API key show up in the error card.

## Fixed
- **Claude chats with higher speed start again.** If a higher speed was set for Opus, every Claude chat aborted immediately ("unknown option '--fast'"). The speed setting still takes effect.
- **Claude with sandbox.** If "Don't start at all without a sandbox" is off, the chat keeps running without a sandbox where the sandbox cannot start (Linux without bubblewrap, Windows), instead of aborting every answer.
- **ZCode installs the right program.** Until now "Install" installed an unrelated npm package of the same name. On the Mac, ZCode now comes from Z.ai's Homebrew cask; on Windows and Linux, AyCode shows the download page. Pi installs and updates through its real npm package.
- **Kimi Code instead of kimi-cli.** The old kimi-cli is no longer maintained and no longer starts chats. Installation and updates now lead to Kimi Code, also from an old installation.
- **Antigravity without sign-in** no longer hangs for 60 seconds but shows the sign-in hint right away.
- **Import from T3 Code** reads the new `statev2.sqlite` database (T3 Code 0.0.45 and later) and older schemas. Newer chats used to be missing, and an unreadable database made the section silently disappear.
- **Running clocks tick**, even while an answer is streaming. "Running for" used to stay at 0:00.
- **OMP:** the reasoning levels follow OMP's order, XHigh below Max.

## Performance
- **Large graph on the iPhone:** thousands of notes are laid out in about one second instead of several.
- **DeepSeek Harness saves tokens:** AyCode's instructions go along only once per dsh session, and later turns send only the new message instead of the whole history.

## For those following along
- 7.0.1 was never tagged or published. Its changes (status pills, rolling numbers, diff comments, the command palette, the Claude speed fix) are listed here.
- AyCode Cloud needs a redeploy for the team inbox, invitations by GitHub name and joining in the browser. After that, `/v1/health` lists `team-3`, `team-4` and `team-5`. Until then these features stay off.
- The Watch app has a new extension for the complications (`me.ayont.aycode.mobile.watchkitapp.widgets`) with the app group `group.me.ayont.aycode.mobile`. On the first archive, Xcode has to create the profiles for it.
- The Playwright reference images are at the state of 7.0.1. Views that have changed since (including Settings, the share dialog and the sidebar) need to be regenerated on the Mac.

Desktop 7.1.0 · Android 7.1.0 (71000) · iPhone und Apple Watch 7.1.0 (62) folgen über TestFlight

Teams und Aylinge rücken zusammen: Gruppenchats mit mehreren Aylingen auf jedem Provider, Einladungen per GitHub-Name und Team-Sessions, bei denen man im Browser mitliest, ganz ohne AyCode. Dazu ein Prompt an mehrere Modelle mit Vergleich nebeneinander, Diff-Kommentare, Chats für später, der Verlauf als Stundenzettel, eine Übersicht in den Einstellungen und viel Neues auf iPhone und Apple Watch: Mac wecken, aus der Mitteilung antworten, Face ID und Komplikationen. 7.0.1 wurde nicht veröffentlicht, ihre Änderungen sind hier enthalten.

## Neu
- **Team-Session im Browser, ohne AyCode.** Die Einladungsseite bietet „Im Browser mitmachen, ohne AyCode“. Wer mitmachen will, meldet sich mit GitHub an und klopft an. Nach dem Einlass liest er jeden Chat der Sitzung live mit (Text, Werkzeugschritte und Code), sieht die Aufgaben und schreibt im Team-Chat mit. Agenten steuern, Freigaben erteilen und Code bleiben in der App. Die Seite entschlüsselt alles selbst, die Cloud liest weiterhin nichts. Auf dem Handy ist die Seite in Tabs aufgeteilt.
- **Per GitHub-Name einladen.** Im Teilen-Dialog `@name` eintippen und „Einladen“ klicken. Die eingeladene Person sieht die Einladung in der Insel und als Mitteilung und ist mit „Mitmachen“ dabei, ohne anzuklopfen. Einladungen lassen sich zurücknehmen oder ablehnen.
- **Team-Chat wie im Messenger.** Antworten mit Zitat, eigene Nachrichten bearbeiten und löschen, Reaktionen (👍 ❤️ 😂 🎉 👀) und angepinnte Nachrichten über dem Gespräch.
- **Im Team nichts verpassen.** Die Cloud bewahrt Team-Chat, Reaktionen, Kommentare und Aufgaben versiegelt auf. Wer offline war, bekommt beim Zurückkommen alles nach, auch wenn sonst niemand online ist. Nach einem Neustart ist das Gespräch wieder da.
- **Gruppenchats mit Aylingen.** Ein Chat für Menschen und mehrere Aylinge, deren Provider sich frei mischen lassen. Das angepinnte Ayling antwortet sofort (oder entscheidet selbst, oder wartet auf @Name), die anderen reagieren auf @Name, @alle fragt alle. Aylinge holen sich gegenseitig dazu und können neue Spezialisten anlegen. „Gruppe erstellen“ steht in der Aylinge-Liste, auf dem Startbildschirm und im Eingabefeld. Ayling-Chats und Gruppen lesen sich wie ein Messenger, mit Blasen in der Farbe des Aylings.
- **Ayling kopieren.** „Kopie anlegen“ im Profil übernimmt Auftrag, Engine, Ort, Skills und Gedächtnis. Die Routinen der Kopie sind zunächst ausgeschaltet, damit nichts doppelt läuft.
- **Ein Prompt an mehrere Modelle.** Auf der Startseite mit ⇧-Klick (Windows: Umschalt-Klick) bis zu drei weitere Modelle im Picker wählen. Jedes Modell bekommt einen eigenen Chat, in Repositories mit eigenem Worktree. „Antworten vergleichen“ zeigt die Antworten danach nebeneinander, jeweils mit Status, Zeit, Werkzeugaufrufen und geänderten Dateien.
- **Diff-Zeilen kommentieren.** Im Änderungen-Panel zeigt jede Zeile beim Überfahren einen Kommentar-Knopf. „In den Chat“ (oder ⌘/Strg + Enter) legt den Kommentar als Zitat mit Datei, Zeile und Code ins Eingabefeld. Mehrere Kommentare sammeln sich in einer Nachricht.
- **Chats für später.** Im Chat-Menü gibt es „Später“: in einer Stunde, heute Abend, morgen früh oder am Montag. Der Chat wartet im Abschnitt „Später“ und kommt zur gewählten Zeit von selbst zurück, oder schon früher, wenn sich darin etwas tut.
- **Rückfragen mit Bild oder Datei beantworten.** Die Fragekarte hat eine Büroklammer, und ein eingefügtes Bild wird angehängt.
- **Langer eingefügter Text wird zur Datei.** Ab 32 KiB hängt AyCode eingefügten Text als Textdatei an, statt das Eingabefeld zu füllen. „Doch als Text“ macht das rückgängig.
- **Listen setzen sich fort.** Im Eingabefeld führt eine neue Zeile die Liste weiter, wie in AyNotes. Eine leere Zeile beendet sie.
- **Projekte mit eigenen Vorgaben.** Pro Projekt lassen sich Modell und Denkaufwand festlegen, mit denen neue Chats starten. Jede Projektkarte zeigt die Aktivität der letzten 14 Tage. Ein ausgewähltes Projekt zeigt seine Kennzahlen, darunter Kosten und Tokens der letzten 7 Tage.
- **Im Agent-Browser markieren.** Über „Markieren“ in der Leiste oder an der Pille markiert ein Klick ein Element der Seite mit einer Nummer, statt es zu bedienen. Der Agent liest die Markierungen mit, und „In den Chat“ schreibt sie ins Eingabefeld.
- **Verlauf als Stundenzettel.** Der Verlauf hat eine Suche, eine Leiste „Letzte 7 Tage“ und „Wohin die Zeit ging“ mit einem Filter pro App (z. B. „Nur Xcode“). „Stundenzettel“ kopiert einen Tag oder alle Treffer als Markdown.
- **AyNotes: offene Aufgaben.** Die Startseite sammelt die Aufgaben aus den Meetings der letzten 45 Tage, Aufgaben mit Frist zuerst. Abhaken geht dort und auf der Meeting-Seite. „Offene Aufgaben an den Agenten“ schickt nur, was noch offen ist.
- **Graph: Weg zwischen zwei Notizen.** „Weg zu …“ hebt die kürzeste Kette von Links zwischen zwei Notizen hervor.
- **Einstellungen mit Übersicht.** Die Einstellungen öffnen mit einer Übersicht: was gerade deine Aufmerksamkeit braucht und wie es um jeden Bereich steht. Die Seiten Cloud und Handy beginnen mit Status-Kacheln, und die Cloud-Seite listet alle Team-Sessions und Einladungen. Die Navigation ist neu gegliedert, und „Import“ heißt jetzt „Umzug“.
- **Tastenkürzel frei belegen.** Einstellungen › Tastenkürzel (⌘/ bzw. Strg + /) listet alle Kürzel. Globale Kürzel lassen sich neu belegen oder abschalten. Ist eine Taste schon vergeben, lehnt AyCode sie ab.
- **Handys mit „Nur lesen“.** Jedes gekoppelte Handy lässt sich umbenennen und auf „Nur lesen“ stellen. Es sieht dann alles, kann aber nicht schreiben, freigeben, Chats starten oder Einstellungen ändern.
- **Umzug aus mehr Apps.** Der Umzugsassistent erkennt jetzt auch T3 Code, Cline, Pi, Oh My Pi, Grok CLI, Mistral Vibe, Cursor, GitHub Copilot CLI und Qwen Code und zeigt ihre Logos. Importe aus T3 Code und Claudian zeigen, wie weit sie sind („12 von 31 Chats“).
- **AyCodes MCP-Server für mehr Provider.** DeepSeek Harness (ab 0.2), Vibe (ab 2.22), Pi und Antigravity über das SDK bekommen Brain, Agent-Browser und deine eigenen MCP-Server automatisch. Antigravity arbeitet weiter, auch wenn ein Server nicht antwortet.
- **Pi plant.** „Planen“ startet Pi nur mit lesenden Werkzeugen. Das Ergebnis ist ein Plan, den du mit „Plan umsetzen“ startest.
- **Codex: „Ultra“ für GPT-6.1 Sol.** Die Denkstufen kommen jetzt aus dem Modellkatalog von Codex, neue Stufen erscheinen also ohne AyCode-Update.
- **Mehr Ziele in der Befehlspalette.** ⌘K öffnet auch Projektübersicht, Aylinge, AyNotes und Verlauf.

## Neu auf iPhone und Apple Watch
- **Mac wecken.** iPhone und Watch senden echte Wake-on-LAN-Pakete. Kommt das iPhone zurück ins WLAN oder wechselt es das Netz, verbindet es sich sofort und weckt den Mac. Dazu gibt es ein Mac-Widget für Home- und Sperrbildschirm und einen Schalter im Kontrollzentrum.
- **Aus der Mitteilung antworten und freigeben.** Unter einer fertigen Antwort steht „Antworten“, bei Freigaben „Erlauben“ und „Ablehnen“ (mit Face ID). Unter Einstellungen → Mitteilungen wählst du, was sich meldet und ob Titel und Vorschau auf dem Sperrbildschirm erscheinen. Das App-Symbol zählt die Chats, die auf dich warten.
- **Datenschutz & Verhalten.** Sperre mit Face ID (sofort oder nach 1, 5 oder 15 Minuten), eine Abdeckung im App-Umschalter, ein Bildschirm, der wach bleibt, solange ein Agent arbeitet, und ein frei wählbarer Start-Tab.
- **Neuer Chat von überall.** Über Siri („Neuer Chat in AyCode“), Spotlight, Kurzbefehle, die Aktionstaste und `aycode://new`. Auf der Watch startet „Neuer Chat“ mit Projektwahl und Diktat.
- **Komplikationen für die Watch.** Wer arbeitet, wer wartet und welche Grenze am vollsten ist, steht direkt auf dem Zifferblatt.
- **Gruppenchats auf dem iPhone.** Das angepinnte Ayling steht oben, neben jeder Antwort der Avatar des Aylings, das sie geschrieben hat.
- **Alle acht Aylinge-Formen**, auch Geist, Stern, Würfel und Blume, gibt es jetzt auf dem iPhone, in den Widgets und im Bildschirmschoner.

## Verbessert
- **Antworten wirken lebendig.** Jedes Wort einer laufenden Antwort blendet sanft ein. Zeit und Schritte zählen mit, und Leiste, Endpunkt und Rand des Eingabefelds leuchten in der Farbe des antwortenden Providers. Statuswörter verwandeln sich Buchstabe für Buchstabe, und Zahlen (Zeilen, Kontext, Limits, Verbrauch) rollen zu ihrem neuen Wert. Bei reduzierter Bewegung bleibt alles ruhig.
- **Änderungen auf einen Blick.** Über dem Eingabefeld zeigt eine kleine Live-Vorschau, welche Datei der Agent gerade bearbeitet. Wer mit der Maus über „+1 −1“ eines Schritts oder über den Änderungs-Chip fährt, sieht die geänderten Zeilen oder Dateien. In der Seitenleiste zeigen laufende Chats ihre geänderten Zeilen.
- **Die Aufgabenliste des Agenten hakt live ab**, mit rollendem Zähler und einem kurzen Glanz bei jedem Haken.
- **Ruhigere Bedienung.** Löschen und Entfernen fragen direkt am Knopf nach statt in einem Systemdialog. „Kopieren“ wird an Ort und Stelle zum Haken. Ladeplatzhalter erscheinen nur, wenn das Laden wirklich dauert.
- **Seitenleiste und schmale Fenster.** Wartende und abgebrochene Chats tragen eine kurze Pille („Wartet“, „Fehler“), auch in der Befehlspalette. In schmalen Fenstern weichen Chips der Chat-Kopfzeile ganz, statt abgeschnitten zu werden, und die Aktionen im Änderungen-Panel brechen um.
- **Lesbarkeit.** Leise Texte (Hinweise, Zeitangaben) haben in jedem Farbthema mindestens 3:1 Kontrast, die Status-Pillen erfüllen AA.
- **Agent-Browser.** Der Cursor umrandet, was er gleich anklickt, und beim Tippen sieht man jeden Buchstaben. Die Leiste ist ruhiger und hat ein Adressfeld. Das Fenster öffnet sich nur noch, wenn der Agent in einer Web-App arbeitet, nicht für bloßes Nachlesen.
- **Klarere Fehlerkarten.** Lehnt eine CLI AyCodes Optionen ab oder ist sie veraltet, heißt die Karte „CLI-Version passt nicht“ und bietet „CLI aktualisieren“ an. Anmeldeprobleme bei Grok, Pi, OMP und OpenCode führen zur Anmelde-Karte.
- **DeepSeek Harness 0.2.** Denken, Werkzeuge und Antwort erscheinen live, jeder Chat hat seine eigene dsh-Sitzung, und Fehler wie ein fehlender API-Schlüssel stehen in der Fehlerkarte.

## Behoben
- **Claude-Chats mit erhöhtem Tempo starten wieder.** War für Opus ein höheres Tempo eingestellt, brach jeder Claude-Chat sofort ab („unknown option '--fast'“). Das Tempo wirkt weiterhin.
- **Claude mit Sandbox.** Ist „Ohne Sandbox gar nicht starten“ aus, läuft der Chat dort, wo die Sandbox nicht starten kann (Linux ohne bubblewrap, Windows), ohne Sandbox weiter, statt jede Antwort abzubrechen.
- **ZCode installiert das richtige Programm.** Bisher installierte „Installieren“ ein fremdes npm-Paket gleichen Namens. Auf dem Mac kommt ZCode jetzt aus dem Homebrew-Cask von Z.ai, auf Windows und Linux zeigt AyCode die Download-Seite. Pi installiert und aktualisiert sich über sein echtes npm-Paket.
- **Kimi Code statt kimi-cli.** Die alte kimi-cli wird nicht mehr gepflegt und startet keine Chats mehr. Installation und Updates führen jetzt zu Kimi Code, auch von einer alten Installation aus.
- **Antigravity ohne Anmeldung** hängt nicht mehr 60 Sekunden, sondern zeigt sofort den Hinweis zur Anmeldung.
- **Import aus T3 Code** liest die neue Datenbank `statev2.sqlite` (ab T3 Code 0.0.45) und ältere Schemas. Bisher fehlten neuere Chats, und eine unlesbare Datenbank ließ den Abschnitt still verschwinden.
- **Laufende Uhren ticken**, auch während eine Antwort streamt. Bisher blieb „läuft seit“ bei 0:00 stehen.
- **OMP:** Die Denkstufen stehen in der Reihenfolge von OMP, XHigh unter Max.

## Performance
- **Großer Graph auf dem iPhone:** Tausende Notizen sind in etwa einer Sekunde angeordnet statt in mehreren.
- **DeepSeek Harness spart Tokens:** AyCodes Anweisungen gehen nur einmal pro dsh-Sitzung mit, und spätere Züge schicken nur die neue Nachricht statt des ganzen Verlaufs.
